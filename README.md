# 📊 Sales Summary by City. UK – Data Project

## 📝 Project Description

This project focuses on analyzing sales data using **Pivot Tables** and the **SWITCH function** to generate a clear, concise summary of products sold in each city along with the corresponding sales volumes.

## 🧰 Tools & Functions Used

- **Excel / Google Sheets**
- **Pivot Tables** for grouping and summarizing data
- **SWITCH Function** for efficient value mapping and conditional logic

---

## 📈 Results

The final output is a pivot-based summary table that:
- Lists each **product** across different **cities**
- Highlights **total sales volume** per city
- Enables quick comparisons and trend identification
